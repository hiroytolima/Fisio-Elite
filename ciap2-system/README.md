# 🏥 Sistema CIAP-2 - Classificação Internacional de Atenção Primária

Sistema web completo para navegação, busca e visualização da CIAP-2 (Classificação Internacional de Atenção Primária, 2ª Edição).

## 📋 O que é a CIAP-2?

A CIAP-2 é a classificação oficial da **Atenção Primária à Saúde no Brasil**, adotada pelo **e-SUS APS** e pelo **Prontuário Eletrônico do Cidadão (PEC)** [citation:10]. Desenvolvida pela WONCA (Organização Mundial dos Médicos de Família), ela permite classificar:

- **Motivos de consulta** (queixas e sintomas)
- **Procedimentos** (diagnósticos, preventivos, terapêuticos)
- **Doenças e problemas de saúde**

Ao contrário da CID-10, que foca no diagnóstico final, a CIAP-2 classifica todo o **episódio de cuidado**, desde a queixa do paciente até a intervenção realizada [citation:10].

## 📊 Estrutura

A CIAP-2 possui **17 capítulos** (letras A a Z) organizados por sistemas orgânicos [citation:5][citation:2]:

- A - Geral e Inespecífico
- B - Sangue, Órgãos Hematopoiéticos e Linfáticos
- D - Aparelho Digestivo
- F - Olhos
- H - Ouvidos
- K - Aparelho Circulatório
- L - Sistema Musculoesquelético
- N - Sistema Nervoso
- P - Problemas Psicológicos
- R - Aparelho Respiratório
- S - Pele
- T - Endócrino, Metabólico e Nutricional
- U - Aparelho Urinário
- W - Gravidez e Planejamento Familiar
- X - Aparelho Genital Feminino
- Y - Aparelho Genital Masculino
- Z - Problemas Sociais

### 7 Componentes Padronizados

Cada capítulo tem 7 componentes, representados pelos dois dígitos do código [citation:6][citation:12]:

1. **Sinais e Sintomas** (01-29)
2. **Procedimentos Diagnósticos e Preventivos** (30-49)
3. **Medicações, Tratamentos e Procedimentos** (50-59)
4. **Resultados de Exames** (60-61)
5. **Procedimentos Administrativos** (62)
6. **Encaminhamentos e Outras Razões** (63-69)
7. **Doenças e Problemas de Saúde** (70-99)

## 🚀 Funcionalidades

- ✅ Navegação pelos 17 capítulos
- ✅ Visualização por componentes (códigos coloridos)
- ✅ Busca por código ou nome
- ✅ Modal com detalhes de cada rubrica
- ✅ Responsivo (desktop, tablet e mobile)
- ✅ Atalhos de teclado (Ctrl+Shift+F para buscar)
- ✅ Estatísticas em tempo real

## 🗂️ Dados Incluídos

- **17 capítulos** completos
- **700+ rubricas** cobrindo toda a classificação
- Organização por **7 componentes** padronizados

## 💻 Como usar

1. Abra o arquivo `index.html` no seu navegador
2. Clique nas abas para navegar pelos capítulos
3. Cada capítulo mostra as rubricas agrupadas por componente
4. Use a busca para encontrar códigos ou nomes rapidamente
5. Clique no ícone ℹ️ para ver detalhes de cada rubrica
