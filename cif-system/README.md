# 🏥 Sistema CIF - Classificação Internacional de Funcionalidade

Sistema web completo para navegação, busca e visualização da CIF (OMS).

## 📋 Funcionalidades

- ✅ Navegação pelos 4 componentes principais (b, s, d, e)
- ✅ Visualização em árvore hierárquica (capítulos e categorias)
- ✅ Busca por código ou nome
- ✅ Modal com detalhes de cada item
- ✅ Responsivo (funciona em desktop, tablet e mobile)
- ✅ Atalhos de teclado (Ctrl+Shift+F para buscar)
- ✅ Estatísticas em tempo real
- ✅ Expandir/Colapsar todos os nós

## 🚀 Como usar

1. Abra o arquivo `index.html` no seu navegador.
2. Clique nas abas para navegar pelos componentes.
3. Clique nos itens para expandir/colapsar subcategorias.
4. Use a busca para encontrar códigos ou nomes.
5. Clique no ícone ℹ️ para ver detalhes.
