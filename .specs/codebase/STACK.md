# STACK.md — Tech Stack

- **Frontend**: React 19, TypeScript strict, Vite, React Router v7.
- **Styling**: Tailwind CSS v4, Radix UI, Lucide Icons.

- **Backend Managed**: Supabase (PostgreSQL, Supabase Auth, Row Level Security, Edge Functions, Storage).
- **Testing**: Vitest 3.x, Testing Library, Playwright.
